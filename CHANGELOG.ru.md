# Changelog


## Unreleased
- **ADDED**: В релизе есть DMG для установки перетаскиванием (`scripts/build_dmg.sh`) рядом с `.zip`, которым
  по-прежнему пользуется обновление из приложения; `SHA256SUMS.txt` покрывает оба файла.


## 1.1.1 - 23/09/2026
- **CHANGED**: Кнопка обновления стоит сразу за «Обновлено … назад» — лёгкая иконка вместо плашки в дальнем углу.
- **FIXED**: «Досрочные сбросы» стоят вровень со следующим окном лимитов в соседних колонках.


## 1.1.0 - 23/09/2026
- **ADDED**: Подменю аккаунта десктоп-приложений Claude и Codex. Список совпадает с колонками панели; выбор закрывает
  приложение и открывает его под этим аккаунтом.
- **ADDED**: У приложения Claude своя папка данных на каждый аккаунт; при первом переходе на аккаунт нужно один раз
  войти.
- **ADDED**: В приложении Codex переключение подменяет только `~/.codex/auth.json`, поэтому проекты, треды и сайдбар
  остаются на месте; голый `codex` в терминале работает под тем же аккаунтом, что и приложение.
- **ADDED**: Колонка аккаунта, открытого в приложении, подсвечена; подсветка переезжает только после реального
  перезапуска приложения.
- **ADDED**: Добавление аккаунта с пустым именем (или `main`) — вход в стандартное место CLI (`~/.claude` / `~/.codex`)
  вместо отдельного профиля, с предупреждением, если это заменит текущий вход.
- **ADDED**: Понятные ошибки переключения: приложение не закрылось или у аккаунта нет входа.
- **FIXED**: Больше не появляется лишняя колонка Claude «main»: запись Keychain без входа (её пишет голый `claude`) не
  считается аккаунтом, пока в неё не войдут.
- **FIXED**: Окна лимитов без даты сброса сохраняют высоту строки, колонки больше не съезжают относительно друг друга.
- **FIXED**: «Досрочные сбросы» Codex показывают реальное число доступных сбросов.
- **FIXED**: Диалоги открываются поверх панели у чёлки, а не под ней.
- **FIXED**: Незавершённые профили (папка есть, входа нет) можно удалить из меню.
- **REMOVED**: Переключатель «активного аккаунта CLI» через подмену базовой записи: он путался с аккаунтом
  приложения и портил общий вход Claude.
- **CHANGED**: В заметки к релизу попадает раздел версии из `CHANGELOG.md`.


## 1.0.2 - 11/09/2026
- **ADDED**: Пункт меню «О Notch Limits» с текущей версией.
